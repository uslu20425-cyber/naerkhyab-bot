# ربات تلگرام پاکسازی نرخ اسعار واتساپ

> تمام تعاملات روزانه داخل خود تلگرام — بدون نیاز به برنامه جداگانه

رباتی ساده، امن و رایگان برای کسانی که نرخ اسعار را از گروه‌های واتساپ کپی می‌کنند و می‌خواهند بدون دردسر، با یک قالب تمیز و یکسان، فقط پس از تأیید خودشان در گروه تلگرام اختصاصی منتشر کنند.

این پروژه دقیقاً مطابق درخواست شما ساخته شده: حذف خودکار سربرگ‌های واتساپ، حفظ دقیق نرخ‌ها، پیش‌نمایش و سه دکمه **تأیید / ویرایش / لغو** — و مدیریت کامل از داخل تلگرام.

---

## ✨ ویژگی‌ها

- **دریافت پیام کپی‌شده واتساپ** (حتی چند پیام پشت سر هم) با یک پیست ساده
- **پاکسازی هوشمند در تمام خطوط:**
  - حذف `[12/10, 16:57]` ، ساعت، `+93 78 057 7584` ، براکت‌ها و `:` سربرگ
  - حذف کامل عبارت تکراری `نرخیاب دقیق` (با و بدون `*`)
  - حذف نام فرستنده در سربرگ واتساپ
  - حذف خطوط خالی و فاصله‌های اضافی
  - **بدون دست‌کاری متن اصلی نرخ‌ها**
- **حفظ دقیق:**
  - نام ارز/کشور/شهر + پرچم‌ها 🇦🇪 🇹🇷 🇮🇷
  - اعداد صحیح و اعشاری (900, 6.63, 111.90)
  - محدوده‌ها `100 تا 120`
  - عبارت‌های «لفظی»، «بهتر است»، «به دالر» و توضیحات معاملاتی
  - بدون جابه‌جایی خرید/فروش و بدون حدس اعداد
- **قالب خروجی ثابت و خوانا:**
  ```
  💱 **نرخ لحظه‌ای**

  🇦🇪 **دوبی** 🟢 خرید: 900 🔴 فروش: 950
  🇹🇷 **ترکیه** 🟢 خرید: 1150 🔴 فروش: 1200

  📍 **نرخ‌های لفظی**
  هرات ↔ کابل: 100 تا 120؛ هرات بهتر است.
  ```
  عنوان فقط `💱 نرخ لحظه‌ای` — بدون برند، شماره، تاریخ یا امضا
- **جداسازی خودکار** نرخ‌های لفظی از خرید/فروش + حفظ ترتیب اصلی
- **هشدار هوشمند** اگر نرخ‌ها غیرعادی باشند (مثلاً خرید خیلی بیشتر از فروش)
- **پیش‌نمایش + سه دکمه:**
  - `✅ تأیید و انتشار` → فقط با تأیید شما در گروه مقصد منتشر می‌شود
  - `✏️ ویرایش پیام` → متن نهایی را همین‌جا دوباره بفرستید
  - `❌ لغو` → حذف درخواست
- **مدیریت کامل داخل تلگرام:**
  - `/set_target` — تنظیم گروه مقصد
  - `/get_target` — نمایش مقصد فعلی
  - `/status` — وضعیت ربات و دسترسی
  - `/history` — 5 انتشار آخر
  - `/settings` — منوی تنظیمات
  - فوروارد پیام از گروه برای تنظیم خودکار ID
- **امنیت:**
  - فقط `ADMIN_ID` شما اجازه انتشار دارد
  - توکن در `.env` (هرگز در کد منتشر نمی‌شود)
  - جلوگیری از انتشار تکراری با کلیک‌های مکرر
  - مدیریت خطای شبکه و پیام‌های نامعتبر
- **رایگان و بدون هوش مصنوعی پولی:** فقط `python-telegram-bot` + پردازش متن با regex

## 🚀 راه‌اندازی قدم‌به‌قدم (برای فرد مبتدی)

### ۱) ساخت ربات در BotFather

1. در تلگرام به `@BotFather` بروید.
2. `/newbot` بفرستید → نام نمایشی (مثلاً `نرخیاب من`) → نام کاربری با `bot` در انتها (مثلاً `narkhyab_clean_bot`).
3. توکنی مثل `123456:AAH...` دریافت می‌کنید — **کپی کنید**.
4. (اختیاری) `/setdescription` و `/setabout` برای توضیح ربات.
5. (اختیاری) `/setjoingroups` → `Enable` تا بتوانید ربات را به گروه اضافه کنید.
6. (اختیاری) `/setprivacy` → `Disable` اگر می‌خواهید ربات پیام‌های گروه را ببیند (برای این پروژه لازم نیست).

### ۲) گرفتن شناسه مدیر (ADMIN_ID)

- به ربات `@userinfobot` پیام دهید → شناسه عددی شما (مثلاً `123456789`) را می‌دهد.
- یا به ربات خودتان پس از اجرا پیام دهید؛ ربات شناسه شما را در پیام «دسترسی مجاز نیست» نشان می‌دهد.

### ۳) گرفتن شناسه گروه مقصد (TARGET_CHAT_ID)

**روش آسان (فوروارد):**
1. ربات را به گروه تلگرام مقصد اضافه کنید.
2. ربات را **ادمین** کنید (مجوز `Send Messages` کافی است).
3. یک پیام عادی از گروه به پیوی ربات **فوروارد** کنید → ربات شناسه را تشخیص داده و دکمه «تنظیم به عنوان مقصد» را نشان می‌دهد.

**روش دستی:**
1. ربات `@getidsbot` را به گروه اضافه کنید → شناسه گروه (مثل `-1001234567890`) را می‌دهد.
2. یا از سایت `https://api.telegram.org/bot<TOKEN>/getUpdates` پس از ارسال پیام در گروه استفاده کنید.
3. سپس در پیوی ربات: `/set_target -1001234567890`

> نکته: شناسه گروه‌های خصوصی همیشه با `-100` شروع می‌شود. گروه را خصوصی یا عمومی کنید فرقی ندارد، ربات باید ادمین باشد.

### ۴) نصب روی کامپیوتر (ویندوز/مک/لینوکس)

```bash
# 1. پایتون 3.10+ نصب کنید (از python.org)

# 2. پروژه را دانلود یا کلون کنید
git clone <repo-url>
cd <folder>

# 3. محیط مجازی (اختیاری اما پیشنهادی)
python -m venv .venv
# ویندوز:
.venv\Scripts\activate
# مک/لینوکس:
source .venv/bin/activate

# 4. وابستگی‌ها
pip install -r requirements.txt

# 5. تنظیمات
cp .env.example .env
# حالا .env را با notepad باز کنید و پر کنید:
# BOT_TOKEN=توکن_BotFather
# ADMIN_ID=شناسه_شما
# TARGET_CHAT_ID=-100...

# 6. اجرا
python main.py
```

اگر `✅ ربات آماده است` دیدید، به ربات در تلگرام `/start` بفرستید.

### ۵) اجرا روی اندروید (Termux) — کاملاً رایگان

1. از F-Droid برنامه **Termux** را نصب کنید.
2. در Termux:
```bash
pkg update && pkg upgrade
pkg install python git
git clone <repo-url>
cd <folder>
pip install -r requirements.txt
cp .env.example .env
nano .env  # مقادیر را پر کنید، Ctrl+O ذخیره، Ctrl+X خروج
python main.py
```
3. برای اجرای همیشگی: از `termux-wake-lock` یا `nohup python main.py &` استفاده کنید.  
   بهتر است از سرویس‌های هاستینگ زیر برای 24/7 استفاده کنید.

### ۶) اجرا روی هاست رایگان (برای 24/7)

ربات از **Polling** استفاده می‌کند — نیازی به وب‌هوک/دامنه ندارد. هر جا پایتون اجرا شود کافی است.

| سرویس | رایگان؟ | توضیح صادقانه |
|-------|---------|---------------|
| **Render.com** | ✅ 750 ساعت/ماه | بهترین گزینه. بعد از 15 دقیقه بی‌کاری Sleep می‌شود اما Polling با `Keep-Alive` حل می‌شود. کافی است یک Cron هر 10 دقیقه به سرویس ping بزند. |
| **Railway.app** | ⚠️ 5$ اعتبار اولیه | ساده، بدون Sleep، اما پس از اتمام اعتبار پولی می‌شود. |
| **Fly.io** | ✅ 3 ماشین کوچک رایگان | نیاز به کارت، ولی واقعاً رایگان می‌ماند. با `flyctl launch` مستقر کنید. |
| **Replit** | ✅ | سریع برای تست، اما نیاز به Keep Alive (UptimeRobot). |
| **VPS ارزان** | ~ 2-3$ ماهانه | پایدارترین. Hetzner, DigitalOcean, یا سرور ایرانی. |
| **کامپیوتر شخصی** | ✅ | اگر همیشه روشن است، کافی است. |

**مثال استقرار در Render (پیشنهادی):**
1. پروژه را در GitHub بگذارید (بدون `.env`!).
2. در Render → `New → Background Worker` → ریپو را وصل کنید.
3. `Build Command: pip install -r requirements.txt`
4. `Start Command: python main.py`
5. در `Environment` متغیرها را اضافه کنید: `BOT_TOKEN`, `ADMIN_ID`, `TARGET_CHAT_ID`
6. Deploy → لاگ‌ها را ببینید.

**هزینه واقعی:** خود ربات **هیچ هزینه API ندارد**. فقط هزینه هاست است که با Polling و گزینه‌های بالا می‌تواند **صفر** بماند. اگر روزی خواستید از API هوش مصنوعی برای تشخیص بهتر استفاده کنید، آن زمان هزینه دارد — فعلاً لازم نیست.

## 💬 نحوه استفاده روزانه (فقط داخل تلگرام)

1. پیام نرخ را از واتساپ **کپی** کنید (می‌توانید چند پیام را با هم انتخاب و کپی کنید).
2. در پیوی ربات **پیست** کنید و بفرستید.
3. ربات **پیش‌نمایش** تمیز را با عنوان `💱 نرخ لحظه‌ای` نشان می‌دهد + هشدارها (اگر بود).
4. سه دکمه:
   - **✅ تأیید و انتشار** → در گروه مقصد منتشر می‌شود (با تفکیک لفظی‌ها).
   - **✏️ ویرایش پیام** → ربات می‌گوید «متن نهایی را کامل بفرست» → شما متن اصلاح‌شده را می‌فرستید → پیش‌نمایش جدید → تأیید.
   - **❌ لغو** → حذف درخواست.
5. برای انتشار بعدی، دوباره از مرحله 1.

> فقط شما (ADMIN_ID) می‌توانید منتشر کنید. دیگران اگر به ربات پیام دهند، «دسترسی مجاز نیست» می‌بینند.

- **منوی شیشه‌ای** زیر هر پیام برای دسترسی سریع

## 🔒 امنیت

- توکن هرگز در کد نیست؛ فقط در `.env` یا متغیر محیطی هاست.
- `config.json` شناسه گروه و تاریخچه را نگه می‌دارد، نه توکن.
- `ADMIN_ID` اگر تنظیم نشود، ربات هشدار می‌دهد و همه را مجاز می‌بیند — **حتماً تنظیم کنید**.
- ربات در گروه فقط پیام منتشر می‌کند، نه می‌خواند (نیازی به Privacy Disable نیست).
- لاگ‌ها شامل متن نرخ نمی‌شوند.

## 🛠 عیب‌یابی

| مشکل | علت و راه‌حل |
|------|--------------|
| `BOT_TOKEN تنظیم نشده` | `.env` را ساختید؟ نام دقیق `BOT_TOKEN=` باشد، بدون فاصله اضافی. |
| `Chat not found` | ربات در گروه نیست یا ادمین نیست. اضافه + ادمین کنید، دوباره `/set_target` بزنید. |
| `Not enough rights to send` | ربات ادمین نیست یا مجوز ارسال ندارد. در تنظیمات گروه → Admins → تیک Send Messages. |
| پیش‌نمایش نمی‌آید | متن خیلی کوتاه بود (<10 حرف) یا فقط دستور بود. پیام کامل واتساپ را بفرستید. |
| دکمه تأیید کار نمی‌کند | گروه مقصد تنظیم نشده (`/get_target` بزنید) یا شما ADMIN نیستید (شناسه را چک کنید). |
| متن به هم ریخته | از HTML استفاده می‌کنیم. اگر کاراکتر خاص `<` در نرخ بود، خودکار escape می‌شود. |
| ربات Sleep می‌شود (Render) | از UptimeRobot هر 5 دقیقه به URL سرویس ping بزنید یا Worker را به Web Service تبدیل کنید. |
